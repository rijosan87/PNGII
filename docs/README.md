# Start here

## What it does

PNG Icon Injector lets you use any PNG, from a plain icon to full color 3D art, in SkyUI menus. No Flash or SWF tools needed.

- **Item Icons**: Replace icons in TrueHUD Recent Loot, Inventory, Container, Barter, Gift, Magic, Favorites, Crafting menus.
- **Item Status Icons**: Add status indicators after item names, such as Quest Item, New, Museum, Best in Class, Ingredient Effects, and more.
- **Category Icons**: Replace the icons in SkyUI's category bar.
- **Full Color PNG**: Use anything from simple monochrome to 3D renders without quality loss.
- **No SWF Editing**: No Flash tools or manual editing required.
